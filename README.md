# NoteBlockSongs
The most complete NBS songs as far as I know that contains at least 600 songs. Provided by multiples sources accros the years. Duplicate can exist.
- Use in any program that can uses .nbs files
- Make your own with NoteBlock Studio

### Installation
Depending on the plugin, drag any .nbs file into the right folder. Many plugins uses /<PLUGINNAME>/songs.
